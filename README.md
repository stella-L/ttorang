# 또랑또랑 · 판소리 연습장

선생님과의 수업 녹음을 **그대로 완벽하게 숙지**하기 위한 개인 연습 도구입니다.
서버 없이 동작하며, 음악 파일은 **사용자 기기(브라우저)에만** 저장됩니다.

## 1단계(MVP) 기능
- 🎵 **녹음 파일 불러오기** — 폰/PC의 오디오 파일을 불러와 로컬(IndexedDB)에 저장
- 🔁 **A-B 구간 반복** — 어려운 한 구절을 무한 반복
- ⏩ **배속 조절 (음정 유지)** — 0.5×~1.5×, 느리게 들어도 소리 높이 그대로
- 📜 **사설 붙이기 + 탭 싱크** — 사설을 줄 단위로 붙이고, 재생하며 줄을 탭해 시간 싱크
  - 재생 중 현재 줄 자동 하이라이트/스크롤, 줄 탭 → 그 지점 점프, 줄별 🔁 반복
- 📝 **타임스탬프 메모** — 특정 지점에 메모를 찍고 탭으로 바로 이동
- 📱 **PWA** — "홈 화면에 추가"하면 앱처럼 사용, 오프라인 동작

## 로컬에서 실행
```bash
# 이 폴더에서
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```
> 파일을 직접 열지(`file://`) 말고 반드시 로컬 서버로 여세요. (서비스워커·오디오 정책 때문)

## GitHub Pages 배포
1. 이 폴더를 GitHub 저장소에 push (index.html이 루트에 있어야 함)
2. 저장소 **Settings → Pages → Source: main 브랜치 / 루트(/)** 선택
3. 몇 분 뒤 `https://<사용자명>.github.io/<저장소명>/` 에서 접속
4. 폰 브라우저에서 열고 **"홈 화면에 추가"** → 앱처럼 사용

## 사용 팁
- **사설 싱크:** 사설 저장 → `🎯 싱크` → 재생되면서 각 줄이 **시작되는 순간** 그 줄을 탭. 한 번 찍으면 계속 유지됩니다.
- **한 줄만 반복:** 싱크된 줄 오른쪽 `🔁` → 그 구절만 반복 재생.
- **백업:** (3단계 예정) 지금은 같은 브라우저에서만 데이터가 유지됩니다. 브라우저 데이터를 지우면 사라지니 주의.

## 파일 구조
```
index.html      화면 구조
style.css       스타일 (먹+단청, 다크모드)
app.js          로직 (IndexedDB 저장, 재생/A-B/배속, 가사 싱크, 메모)
manifest.json   PWA 설정
sw.js           서비스워커 (오프라인 캐시)
icon.svg        앱 아이콘
```
